# Chabot Furia 
Este é um projeto de um protótipo de um chatbot feito para fãs do time de CS:GO da FURIA, desenvolvido com React.js.
O objetivo é proporcionar informações rápidas sobre jogadores, calendário de jogos e redes sociais da furia. 

  <br>

## Preview 
![Funcionamento do Chatbot](./assets/chatbot-furia.gif)

  <br>

## 🛠 Funcionalidades
- 📅 Ver o calendário de próximos jogos da FURIA
- 🧑‍💻 Consultar informações sobre jogadores
- 🌎 Acessar as redes sociais oficiais
- 🤖 Interação dinâmica via chat.
  
  <br>

## 🎯 Melhorias Futuras

- JavaScript (ES6+)
- CSS3
- HTML5
